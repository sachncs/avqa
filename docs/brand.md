# AVQA brand system

AVQA uses a technical-infrastructure identity: precise, quiet, and evidence-led.
The mark combines a routed tree with an A-shaped signal path to represent
coarse-to-fine attention.

## Assets

- `site/public/avqa-mark.svg` — compact mark for navigation, avatars, and favicons.
- `site/public/avqa-wordmark.svg` — horizontal lockup for larger surfaces.
- `site/public/favicon.svg` — small-size browser icon.

## Usage

- Keep clear space around the mark equal to the height of its inner signal path.
- Use the full-color mark on dark surfaces; use a monochrome version when color
  would compete with technical content.
- Do not stretch, rotate, add shadows to, or redraw the mark.
- Prefer the wordmark at widths above 180px; use the compact mark below that.

## Core palette

`#06080F` ink, `#7C8CFF` routing accent, `#7DF9FF` signal accent, and `#F7F8FA`
foreground. Body copy uses the ink scale from `site/src/index.css` and should
remain readable against the ink background.
