# AVQA brand system

AVQA uses a technical-infrastructure identity: precise, quiet, and evidence-led.
The mark combines a routed tree with an A-shaped signal path to represent
coarse-to-fine attention.

## Assets

- `site/public/avqa-mark.svg` — compact mark for navigation, avatars, and favicons.
- `site/public/avqa-wordmark.svg` — horizontal lockup for navigation and larger surfaces.
- `site/public/avqa-mark-light.svg` and `avqa-wordmark-light.svg` — full-color artwork for light surfaces.
- `site/public/avqa-mark-mono-{dark,light}.svg` and `avqa-wordmark-mono-{dark,light}.svg` — monochrome variants for single-color contexts.
- `site/public/favicon.svg` — small-size browser icon with optical corrections.
- `site/public/og-image.svg` — 1200×630 social preview artwork.

## Usage

- Keep clear space around the mark equal to the height of its inner signal path.
- Use the full-color mark on dark surfaces; use a monochrome version when color
  would compete with technical content.
- Do not stretch, rotate, add shadows to, or redraw the mark.
- Prefer the wordmark at widths above 180px; use the compact mark below that.
- Use the dark-surface artwork on the site's dark background. Do not recolor the
  signal gradient or reduce the mark below 24px; use the favicon at smaller
  sizes.
- Social previews use the standalone 1200×630 artwork so they do not depend on
  external image references embedded inside an SVG.

## Core palette

`#06080F` ink, `#7C8CFF` routing accent, `#7DF9FF` signal accent, and `#F7F8FA`
foreground. The subdued text tokens were raised to retain at least 4.5:1
contrast against the site's ink surfaces for small text; verify contrast again
when placing text on a new surface or introducing another palette.
